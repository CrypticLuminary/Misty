# Contributing

Read `AGENTS.md` and `CURRENT_STATE.md` before changing code.

Work in small branches/PRs. State the problem, scope, acceptance criteria, tests and security/privacy impact. Keep unrelated refactors separate.

Do not commit secrets or real private user media as fixtures. Use generated/synthetic fixtures.

A change is not complete until applicable formatting, lint, type checks, tests and security gates pass and durable architectural changes are documented.
